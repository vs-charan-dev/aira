# AIRA invoice demo

The preview executes invoice.js with the displayed price and discount. The
discount is deliberately treated as a currency amount instead of a percentage.
Ask AIRA to fix invoice.js without changing tests or package configuration.
Five independent Node tests verify the calculation. There are no dependencies.

Use Reset demo to broken version in AIRA's Invoice Demo to repeat the demo.
Only this dedicated disposable project is reset; other projects are preserved.
